# 🚀 Руководство по обновлению до расширенной версии

## Что нового?

### ✨ Новые возможности:

1. **🔐 Автоматическое извлечение кодов** - бот автоматически находит и выделяет коды подтверждения в письмах
2. **📧 Множественные email** - создавайте и управляйте несколькими email-адресами одновременно
3. **📱 QR-коды** - генерация QR-кодов для быстрого ввода email на других устройствах
4. **⭐ Избранное** - сохраняйте важные письма в избранное
5. **📜 История** - автоматическое сохранение всех просмотренных писем
6. **🔄 Автопроверка** - настраиваемая автоматическая проверка новых писем с уведомлениями
7. **🔍 Поиск** - поиск по истории писем (по теме, отправителю, содержимому)
8. **⚙️ Настройки** - гибкая настройка интервала проверки, предпочитаемого домена
9. **👑 Админ-панель** - для владельца бота (статистика, рассылки)

---

## 📦 Установка зависимостей

Обновленная версия требует дополнительных библиотек:

```bash
pip install -r requirements.txt
```

**Новые зависимости:**
- `qrcode` - генерация QR-кодов
- `Pillow` - обработка изображений
- `apscheduler` - планировщик задач для автопроверки

---

## 🗂️ Структура файлов

### Основные файлы:
- `bot.py` - базовая версия (управление через кнопки)
- `bot_advanced.py` - **расширенная версия с всеми функциями**

### Модули:
- `tempmail.py` - работа с API 1secmail
- `database.py` - расширенная база данных
- `code_extractor.py` - извлечение кодов подтверждения
- `qr_generator.py` - генерация QR-кодов
- `search.py` - поиск по письмам
- `admin.py` - админ-панель

## ⚙️ Настройка

### 1. Создайте файл `.env`

```bash
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
ADMIN_ID=ваш_telegram_id  # опционально, для админ-панели
```

**Как узнать свой Telegram ID:**
- Напишите боту [@userinfobot](https://t.me/userinfobot)
- Или [@getidsbot](https://t.me/getidsbot)

### 2. База данных

База автоматически обновится при первом запуске расширенной версии.

**Новые таблицы:**
- `message_history` - история писем
- `user_settings` - настройки пользователей

**Если возникли проблемы:**
```bash
# Удалите старую базу (ВНИМАНИЕ: удалятся все данные!)
del users.db

# Бот создаст новую при запуске
```

## 📱 Использование новых функций

### 1. Создание email с QR-кодом

1. Нажмите **"📧 Создать почту"**
2. Выберите домен или используйте быстрое создание
3. Получите email + QR-код автоматически

### 2. Просмотр писем с автоизвлечением кодов

1. Нажмите **"📬 Проверить почту"**
2. Выберите письмо
3. Код подтверждения будет **автоматически выделен** вверху письма

**Пример:**
```
🔐 КОД: 123456 👈 Нажми для копирования
```

### 3. Работа с избранным

- При просмотре письма нажмите **"⭐ В избранное"**
- Просмотр избранного: кнопка **"⭐ Избранное"** в главном меню

### 4. История писем

- Все просмотренные письма сохраняются автоматически
- Просмотр: кнопка **"📜 История"** в главном меню
- Поиск по истории (в разработке)

### 5. Множественные email

1. Нажмите **"📮 Мои email"**
2. Увидите список всех активных адресов
3. Для каждого доступны:
   - 📋 Копирование
   - 📱 Генерация QR-кода
   - ➕ Добавление нового

### 6. Автопроверка

1. Нажмите **"⚙️ Настройки"**
2. Включите **"🔄 Автопроверка"**
3. Выберите интервал: 1, 5 или 10 минут
4. Получайте автоматические уведомления о новых письмах!

### 7. Настройки

**⚙️ Настройки** позволяют:
- Включить/выключить автопроверку
- Установить интервал проверки (1/5/10 мин)
- Выбрать предпочитаемый домен (.com/.org/.net)

## 🐛 Возможные проблемы

### 1. Ошибка импорта модулей
```
ModuleNotFoundError: No module named 'qrcode'
```
**Решение:**
```bash
pip install qrcode Pillow apscheduler
```

### 2. Ошибка базы данных
```
sqlite3.OperationalError: no such column: is_favorite
```
**Решение:** Удалите `users.db` и перезапустите бота

### 3. QR-код не генерируется
**Проверьте:**
- Установлен ли `Pillow`: `pip install Pillow`
- Права на создание файлов в директории

### 4. Автопроверка не работает
**Проверьте:**
- Включена ли она в настройках
- Есть ли активный email
- Нет ли ошибок в логах

## 📈 Производительность

### Рекомендации:

**Для небольшого количества пользователей (<100):**
- `bot_advanced.py` работает отлично
- Автопроверка каждые 5 минут

**Для большого количества (>100):**
- Увеличьте интервал автопроверки до 10 минут
- Рассмотрите использование PostgreSQL вместо SQLite
- Используйте Redis для кэширования

## 🔄 Обновление с базовой версии

Если вы уже используете `bot.py`:

1. **Сохраните данные:**
   ```bash
   copy users.db users.db.backup
   ```

2. **Установите новые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите расширенную версию:**
   ```bash
   python bot_advanced.py
   ```
   
   База данных **автоматически обновится** с сохранением пользователей и email

4. **Проверьте работу:**
   - Откройте бота в Telegram
   - Нажмите `/start`
   - Проверьте новые кнопки
