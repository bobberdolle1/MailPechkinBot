# 🚀 MailPechkinBot - Продвинутый Telegram-бот для временной почты

Полнофункциональный Telegram-бот на Python для работы с временной почтой через сервис 1secmail.com с расширенными возможностями.

## ✨ Основные возможности

### 📧 Работа с Email
- **Множественные адреса** - создавайте несколько email одновременно
- **Выбор домена** - 1secmail.com, .org, .net
- **QR-коды** - генерация QR для быстрого ввода email
- **Управление** - удаление и создание новых адресов

### 🔐 Умные функции
- **Автоизвлечение кодов** - автоматическое распознавание кодов подтверждения
- **Автопроверка** - периодическая проверка новых писем
- **Уведомления** - автоматические уведомления о новых письмах
- **Поиск** - поиск по истории писем

### 💾 Хранение и организация
- **История** - автоматическое сохранение просмотренных писем
- **Избранное** - сохраняйте важные письма
- **Фильтрация** - поиск по отправителю, теме, содержимому

### ⚙️ Настройки
- **Гибкие настройки** - интервал автопроверки, предпочитаемый домен
- **Статистика** - детальная статистика использования
- **Админ-панель** - управление ботом и рассылки

## 🚀 Быстрый старт

### Требования

- Python 3.7 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

### Установка

1. **Клонируйте репозиторий или скачайте файлы**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте файл `.env` на основе `.env.example`:**
```bash
copy .env.example .env
```

4. **Добавьте токен бота в файл `.env`:**
```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
```

5. **Запустите бота:**
```bash
python bot.py
```

## 🎮 Использование

### Управление ботом

Бот работает **полностью через кнопки** - никаких команд!

**Единственная команда:** `/start` - запуск бота и показ клавиатуры

### Кнопки управления

После запуска у вас появится постоянная клавиатура с кнопками:

- 📧 **Создать новую почту** - генерация временного email
- 📬 **Проверить почту** - просмотр входящих писем
- 📮 **Мой email** - показать текущий активный адрес
- 🗑️ **Удалить почту** - удаление текущего email
- ℹ️ **Информация** - о боте и статистика
- ❓ **Помощь** - инструкция по использованию

### Как пользоваться

1. **Создание почты** - нажмите кнопку "📧 Создать новую почту"
2. **Проверка писем** - нажмите "📬 Проверить почту"
3. **Чтение письма** - выберите письмо из списка (Inline-кнопки)
4. **Просмотр адреса** - нажмите "📮 Мой email"
5. **Удаление** - нажмите "🗑️ Удалить почту" (потребуется подтверждение)

## 🛠️ Технологии

- **Python 3.7+** - язык программирования
- **python-telegram-bot 20.7** - библиотека для работы с Telegram Bot API
- **aiohttp** - асинхронные HTTP-запросы к API 1secmail
- **sqlite3** - база данных для хранения пользователей и email
- **python-dotenv** - управление переменными окружения

## 🌐 API 1secmail

Бот использует бесплатный API сервиса [1secmail.com](https://www.1secmail.com/):

- Генерация временных email без регистрации
- Поддержка доменов: 1secmail.com, 1secmail.org, 1secmail.net
- Получение входящих писем в реальном времени
- Документация API: https://www.1secmail.com/api/

## ⚠️ Важные замечания

- **Безопасность:** Не используйте временные email для важной информации
- **Время жизни:** Письма хранятся ограниченное время (обычно несколько часов)
- **Публичность:** Email-адреса доступны всем, кто их знает
- **Ограничения:** Один пользователь = один активный email (старые удаляются)

## 🚀 Деплой

### На VPS (Ubuntu/Debian)

```bash
# Установка зависимостей
sudo apt update
sudo apt install python3 python3-pip git -y

# Клонирование репозитория
git clone <ваш_репозиторий>
cd MailPechkinBot

# Установка Python пакетов
pip3 install -r requirements.txt

# Настройка .env файла
nano .env  # добавьте токен

# Запуск в фоновом режиме
nohup python3 bot.py > bot.log 2>&1 &
```

### Использование systemd (рекомендуется)

Создайте файл `/etc/systemd/system/mailpechkin.service`:

```ini
[Unit]
Description=MailPechkin Telegram Bot
After=network.target

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/MailPechkinBot
ExecStart=/usr/bin/python3 /path/to/MailPechkinBot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Запуск:
```bash
sudo systemctl daemon-reload
sudo systemctl enable mailpechkin
sudo systemctl start mailpechkin
sudo systemctl status mailpechkin
```

## 💾 База данных

Бот использует SQLite с расширенной структурой:

### Таблицы:
- **users** - информация о пользователях
- **user_emails** - активные email-адреса (поддержка множественных)
- **message_history** - история полученных писем
- **user_settings** - настройки пользователей

### Возможности:
- Автоматическое создание базы при первом запуске
- Индексы для быстрого поиска
- Сохранение истории и избранного
- Пользовательские настройки

## 🐛 Решение проблем

### Бот не запускается

- Проверьте наличие токена в `.env` файле
- Убедитесь, что установлены все зависимости: `pip install -r requirements.txt`
- Проверьте версию Python: `python --version` (должна быть 3.7+)

### Не приходят письма

- API 1secmail может быть временно недоступен
- Проверьте правильность email-адреса
- Подождите несколько минут и попробуйте снова

### Ошибки при работе с БД

- Проверьте права на запись в директорию бота
- Удалите файл `users.db` для пересоздания базы
